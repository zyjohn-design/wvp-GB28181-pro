# 外部系统视频接入与云台控制接口文档

文档版本：V1.0  
编制日期：2026-09-17  
适用系统：WVP GB28181 视频平台（当前 ARM64 离线部署包同样适用）  
接口根地址：`http(s)://<WVP地址>:<Web端口>`

本文档面向需要调用 WVP 接口的外部系统，覆盖两种场景：

1. 外部平台（如宇视平台/NVR）通过 GB/T 28181 把设备目录和视频接入 WVP；
2. 外部业务系统通过 HTTP API 从 WVP 查询通道、启动/停止视频，并控制云台。

> 下文中的 `deviceId`、`channelId`、`commonChannelId` 都是示例。实际值必须先通过查询接口取得，不能自行截取或改写 20 位国标编号。

## 1. 接入模型和编号约定

```text
宇视平台/NVR（GB28181下级平台）
       │ REGISTER / Catalog / INVITE / DeviceControl
       ▼
WVP（GB28181上级平台 + 流媒体）
       ▲
       │ access-token + HTTP API
外部业务系统（网页、调度系统、第三方应用）
```

| 名称 | 含义 | 在接口中的使用方式 |
|---|---|---|
| 设备国标编号 | 下级设备或下级平台的 20 位 GB 编号 | 直连设备接口路径中的 `deviceId` |
| 通道国标编号 | 摄像机/目录的 20 位 GB 编号 | 直连设备接口路径中的 `channelId` |
| 通用通道数据库 ID | WVP `wvp_gb_channel` 的自增整数 `id` | `/api/common/channel/*` 的 `channelId` |
| 目录节点 | 行政区、分组、下级平台等非视频资源 | 可以浏览和查询，但不能播放或控制云台 |
| 视频通道 | 可产生实时 RTP 流的摄像机资源 | 才能调用播放和 PTZ 接口 |

最容易出错的地方是把 20 位国标通道编号传给通用接口。通用接口要传数据库整数 ID；直连接口才传 20 位国标编号。

## 2. 认证

### 2.1 获取 JWT

当前登录接口同时支持 GET 和 POST。密码参数必须是 32 位 MD5（小写或大写均可，不带连字符），不是明文密码。

```bash
WVP='http://127.0.0.1:18080'
USER='admin'
PASSWORD_MD5='<32位MD5>'

curl -sS -X POST "$WVP/api/user/login" \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  --data-urlencode "username=$USER" \
  --data-urlencode "password=$PASSWORD_MD5"
```

成功返回统一结构 `{"code":0,"msg":"成功","data":{...}}`，其中 `data.accessToken` 是 JWT；响应头也会返回 `access-token`。后续请求任选其一：

```bash
TOKEN='<登录返回的accessToken>'
curl -sS "$WVP/api/device/query/devices?page=1&count=15&query=" \
  -H "access-token: $TOKEN"
```

也可以把 token 作为同名查询参数传递：`?access-token=<TOKEN>`。浏览器 WebSocket 鉴权使用 `Sec-WebSocket-Protocol` 传递同一个 token。

JWT 默认有效期为 30 分钟。过期后重新登录；不要把 token 写入前端源码、日志或对外文档。

如果配置项 `interface-authentication` 被关闭，服务端会放行大部分 API，但这不适合作为外部系统长期集成方案；接口文档仍按启用认证的生产模式编写。

### 2.2 API Key（推荐给服务到服务调用）

管理员登录后，可在“用户管理 → API Key”创建长期凭证。相关管理接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/userApiKey/add` | `userId` 必填；`app`、`remark`、`expiresAt`、`enable` 可选 |
| GET | `/api/userApiKey/userApiKeys?page=1&count=20&userId=...` | 查询凭证 |
| POST | `/api/userApiKey/enable?id=...` | 启用 |
| POST | `/api/userApiKey/disable?id=...` | 停用 |
| POST | `/api/userApiKey/reset?id=...` | 重置 |
| DELETE | `/api/userApiKey/delete?id=...` | 删除 |

调用业务接口时使用 `api-key` 请求头：

```bash
curl -sS "$WVP/api/common/channel/list?page=1&count=20&channelType=0" \
  -H 'api-key: <API_KEY>'
```

生产环境建议使用 HTTPS、最小权限账号、设置过期时间，并在凭证泄露时立即停用/重置。

## 3. 外部平台把视频接入 WVP（GB/T 28181）

### 3.1 WVP 上级平台参数

现场参数以部署环境为准，下面是当前离线部署的常用值：

| 参数 | 示例值 | 说明 |
|---|---|---|
| Web/API | `http://<WVP地址>:18080` | 外部业务系统调用入口 |
| SIP | `<WVP地址>:8116` | REGISTER、Catalog、INVITE、DeviceControl |
| RTP | `<WVP地址>:10000` | RTP/PS 媒体接收，最终以 SDP 为准 |
| 流媒体 HTTP | WVP 内部 ZLM 端口 | 不应直接把容器内部端口写进浏览器地址 |
| 认证 | 按现场配置 | 无 Digest 时宇视侧选择无认证；启用时需双方配置一致 |
| 编码 | H.264 优先 | H.265 需验证浏览器和播放器兼容性 |
| 字符集 | GB2312/GB18030/GBK/UTF-8 | 宇视中文目录乱码时优先尝试 GB18030 |

### 3.2 下级平台配置内容

宇视侧应以“平台级联/下级平台”方式配置 WVP，而不是把每台摄像机单独注册到 WVP。必须提供：

- 下级平台国标编号及域；
- WVP SIP 地址、端口和 UDP/TCP 协议；
- 下级平台信令出口地址和媒体出口地址；
- 目录共享范围、通道国标编号和通道类型；
- H.264/H.265、RTP/PS、码流类型及 PTZ 权限。

### 3.3 GB28181 交互时序

```text
下级平台 -> WVP       REGISTER / Keepalive
WVP       -> 下级平台 200 OK / Catalog 查询
下级平台 -> WVP       Catalog 响应（目录、视频通道、PTZ能力）
WVP       -> 下级平台 INVITE（含媒体接收地址和端口）
下级平台 -> WVP       RTP/PS
WVP       -> 下级平台 BYE（停止播放）
WVP       -> 下级平台 MESSAGE DeviceControl（云台）
```

成功注册后可通过 `/api/device/query/devices` 查看设备。若只看到目录而不能播放，先确认资源的 `resourceType` 是 `CHANNEL`，而不是 `DIRECTORY`。

## 4. 查询设备、通道和资源类型

### 4.1 分页查询国标设备/下级平台

```http
GET /api/device/query/devices?page=1&count=15&query=&status=true&accessType=DEVICE
```

参数：`page`、`count` 必填；`query`、`status`、`accessType` 可选。`accessType` 取 `DEVICE`（国标设备）或 `PLATFORM`（下级平台）。

典型返回为 PageInfo，核心字段示例：

```json
{
  "list": [{
    "deviceId": "42010000012005000001",
    "name": "宇视下级平台",
    "status": true,
    "accessType": "PLATFORM",
    "transport": "UDP"
  }],
  "pageNum": 1,
  "pageSize": 15,
  "total": 1,
  "pages": 1
}
```

单个设备：

```http
GET /api/device/query/devices/{deviceId}
```

### 4.2 查询设备下的通道/目录

```http
GET /api/device/query/devices/{deviceId}/channels?page=1&count=100&resourceType=CHANNEL
```

可选参数：

| 参数 | 取值 | 说明 |
|---|---|---|
| `online` | `true/false` | 在线过滤 |
| `channelType` | `true/false` | 是否目录/子目录，老版本兼容参数 |
| `resourceType` | `CHANNEL/DIRECTORY` | 推荐使用，明确区分视频和目录 |
| `query` | 文本 | 名称或编号搜索 |

子目录：

```http
GET /api/device/query/sub_channels/{deviceId}/{channelId}/channels?page=1&count=100&resourceType=CHANNEL
```

### 4.3 查询统一通道列表

统一通道列表把国标设备、推流设备、拉流代理等资源汇总到一张表：

```http
GET /api/common/channel/list?page=1&count=100&channelType=0&online=true
```

`channelType`：`0` 国标设备，`1` 推流设备，`2` 拉流代理。返回对象中的 `id` 是后续 `/api/common/channel/*` 接口要用的整数 `commonChannelId`。

## 5. 实时视频接入接口

### 5.1 推荐：统一通道播放

```http
GET /api/common/channel/play?channelId={commonChannelId}
```

示例：

```bash
curl -sS --max-time 40 \
  "$WVP/api/common/channel/play?channelId=123" \
  -H "access-token: $TOKEN"
```

返回格式：

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "app": "rtp",
    "stream": "42010000012005000001_42010000011315000111",
    "flv": "http://host/rtp/<stream>.live.flv",
    "https_flv": "https://host/rtp/<stream>.live.flv",
    "ws_flv": "ws://host/rtp/<stream>.live.flv",
    "wss_flv": "wss://host/rtp/<stream>.live.flv",
    "hls": "http://host/rtp/<stream>/hls.m3u8",
    "rtc": "http://host/index/api/webrtc?app=rtp&stream=<stream>&type=play",
    "rtmp": "rtmp://host:10935/rtp/<stream>",
    "rtsp": "rtsp://host:5540/rtp/<stream>",
    "mediaServerId": "..."
  }
}
```

实际返回字段以启用的流媒体协议为准，常见字段还包括 `fmp4`、`ts`、`ws_hls`、`ws_ts`、`rtmps`、`rtsps`、`rtcs`、`mediaInfo`。外部系统应优先使用返回值，不要自行拼接端口或 stream 名称。

### 5.2 直连国标设备播放

适用于已经拿到设备和通道 20 位国标编号的调用方：

```http
GET /api/play/start/{deviceId}/{channelId}
```

```bash
curl -sS --max-time 40 \
  "$WVP/api/play/start/42010000012005000001/42010000011315000111" \
  -H "access-token: $TOKEN"
```

该接口同样返回 `WVPResult<StreamContent>`。通道必须是视频通道且在线；目录节点、离线通道会返回错误，不应尝试播放。

### 5.3 停止播放

统一通道：

```http
GET /api/common/channel/play/stop?channelId={commonChannelId}
```

直连设备：

```http
GET /api/play/stop/{deviceId}/{channelId}
```

外部系统在关闭窗口、切换通道、用户离开页面时必须调用停止接口，避免下级平台持续推流和媒体资源泄漏。

### 5.4 播放器协议选择

| 场景 | 建议字段 | 说明 |
|---|---|---|
| 浏览器低延迟 | `rtc`/`rtcs` | 需要浏览器 WebRTC 能力和正确 HTTPS/ICE 配置 |
| 浏览器 WebSocket | `wss_flv`/`ws_flv` | 页面 HTTPS 时使用 `wss_flv`，避免混合内容 |
| 浏览器 HLS | `hls`/`https_hls` | 延迟较高，兼容性好 |
| VLC/FFplay/后端 | `rtsp`/`rtmp`/`ts` | 由客户端支持情况决定 |

当前部署通过 Web 网关代理 `/api/` 和 `/rtp/`。浏览器拿到跨网络或容器内部地址时，应将媒体地址改写为当前页面同源地址，不能直接使用容器内部 `:80`。WebSocket 握手必须返回 HTTP `101 Switching Protocols`；若返回 `200`，通常是把 WebSocket URL 指到了普通 HTTP 代理或错误端口。

## 6. 云台控制接口

### 6.1 控制前提

- 资源必须是 `CHANNEL` 视频通道，不是行政区、分组或下级平台目录；
- 摄像机/NVR 必须支持 GB28181 DeviceControl，且宇视侧已授权 PTZ；
- 通道在线、下级平台注册正常；
- 方向键按下发送方向命令，松开必须发送 `stop`；
- 通过下级平台级联时，WVP 会把命令路由到实际源设备，不需要外部系统直连宇视 SIP 端口。

### 6.2 推荐：统一通道 PTZ（使用整数 commonChannelId）

#### 方向、变倍

```http
GET /api/common/channel/front-end/ptz?channelId={id}&command={command}&panSpeed=50&tiltSpeed=50&zoomSpeed=50
```

`command` 允许：`left`、`right`、`up`、`down`、`upleft`、`upright`、`downleft`、`downright`、`zoomin`、`zoomout`、`stop`。速度范围均为 `0-100`，不传默认 `50`。

示例：

```bash
# 按下“向左”
curl -sS "$WVP/api/common/channel/front-end/ptz?channelId=123&command=left&panSpeed=50&tiltSpeed=50&zoomSpeed=50" \
  -H "access-token: $TOKEN"

# 松开按键，必须停止
curl -sS "$WVP/api/common/channel/front-end/ptz?channelId=123&command=stop" \
  -H "access-token: $TOKEN"
```

#### 聚焦、光圈、雨刷和辅助开关

| 功能 | 路径 | 参数 |
|---|---|---|
| 聚焦 | `/api/common/channel/front-end/fi/focus` | `channelId`、`command=near\|far\|stop`、`speed(0-100)` |
| 光圈 | `/api/common/channel/front-end/fi/iris` | `channelId`、`command=in\|out\|stop`、`speed(0-100)` |
| 雨刷 | `/api/common/channel/front-end/wiper` | `channelId`、`command=on\|off` |
| 辅助开关 | `/api/common/channel/front-end/auxiliary` | `channelId`、`command=on\|off`、`auxiliaryId` |

#### 预置位

| 功能 | 路径 | 参数 |
|---|---|---|
| 查询 | `/api/common/channel/front-end/preset/query` | `channelId` |
| 设置 | `/api/common/channel/front-end/preset/add` | `channelId`、`presetId`、`presetName` |
| 调用 | `/api/common/channel/front-end/preset/call` | `channelId`、`presetId` |
| 删除 | `/api/common/channel/front-end/preset/delete` | `channelId`、`presetId` |

#### 巡航、扫描、看守位和拉框变倍

```text
/api/common/channel/front-end/tour/point/add       channelId,tourId,presetId
/api/common/channel/front-end/tour/point/delete    channelId,tourId,presetId
/api/common/channel/front-end/tour/speed           channelId,tourId,speed,presetId
/api/common/channel/front-end/tour/time            channelId,tourId,time,presetId
/api/common/channel/front-end/tour/start           channelId,tourId
/api/common/channel/front-end/tour/stop            channelId,tourId
/api/common/channel/front-end/scan/start            channelId,scanId
/api/common/channel/front-end/scan/stop             channelId,scanId
/api/common/channel/front-end/scan/set/left         channelId,scanId
/api/common/channel/front-end/scan/set/right        channelId,scanId
/api/common/channel/front-end/scan/set/speed        channelId,scanId,speed
/api/common/channel/front-end/home_position         channelId,enabled,resetTime,presetIndex
/api/common/channel/front-end/drag_zoom_in          channelId,length,width,midPointX,midPointY,lengthX,lengthY
/api/common/channel/front-end/drag_zoom_out         channelId,length,width,midPointX,midPointY,lengthX,lengthY
```

巡航/扫描速度和停留时间按接口注释使用 `1-4095`；具体设备可能不支持全部能力，收到设备错误时应向用户显示 `msg`。

### 6.3 直连设备 PTZ（使用 20 位国标编号）

直连接口适用于不使用统一通道数据库 ID 的调用方：

```http
GET /api/front-end/ptz/{deviceId}/{channelId}?command=left&horizonSpeed=100&verticalSpeed=100&zoomSpeed=8
```

参数范围：`horizonSpeed`、`verticalSpeed` 为 `0-255`；`zoomSpeed` 为 `0-15`。方向命令与统一接口相同，`stop` 会将速度清零。

```bash
curl -sS "$WVP/api/front-end/ptz/42010000012005000001/42010000011315000111?command=zoomin&zoomSpeed=8" \
  -H "access-token: $TOKEN"
curl -sS "$WVP/api/front-end/ptz/42010000012005000001/42010000011315000111?command=stop" \
  -H "access-token: $TOKEN"
```

同一组直连接口还包括（所有接口均为 GET）：

```text
/api/front-end/fi/iris/{deviceId}/{channelId}       command=in|out|stop,speed(0-255)
/api/front-end/fi/focus/{deviceId}/{channelId}      command=near|far|stop,speed(0-255)
/api/front-end/preset/query/{deviceId}/{channelId}
/api/front-end/preset/add/{deviceId}/{channelId}    presetId(1-255)
/api/front-end/preset/call/{deviceId}/{channelId}   presetId(1-255)
/api/front-end/preset/delete/{deviceId}/{channelId} presetId(1-255)
/api/front-end/cruise/point/add/{deviceId}/{channelId}       cruiseId,presetId
/api/front-end/cruise/point/delete/{deviceId}/{channelId}    cruiseId,presetId
/api/front-end/cruise/speed/{deviceId}/{channelId}           cruiseId,speed(1-4095)
/api/front-end/cruise/time/{deviceId}/{channelId}            cruiseId,time(1-4095)
/api/front-end/cruise/start/{deviceId}/{channelId}           cruiseId
/api/front-end/cruise/stop/{deviceId}/{channelId}            cruiseId
/api/front-end/scan/start/{deviceId}/{channelId}             scanId
/api/front-end/scan/stop/{deviceId}/{channelId}              scanId
/api/front-end/scan/set/left/{deviceId}/{channelId}          scanId
/api/front-end/scan/set/right/{deviceId}/{channelId}         scanId
/api/front-end/scan/set/speed/{deviceId}/{channelId}         scanId,speed(1-4095)
/api/front-end/wiper/{deviceId}/{channelId}         command=on|off
/api/front-end/auxiliary/{deviceId}/{channelId}     command=on|off,switchId
```

需要发送原始国标 A.3.1 控制码时使用：

```http
GET /api/front-end/common/{deviceId}/{channelId}?cmdCode=...&parameter1=...&parameter2=...&combindCode2=...
```

其中 `parameter1/2` 为 `0-255`，`combindCode2` 为 `0-15`。一般业务系统优先使用语义化的 `ptz`、`preset` 等接口。

### 6.4 统一返回和错误处理

统一通道 PTZ 返回 `WVPResult`：

```json
{"code": 0, "msg": "成功", "data": "..."}
```

常见失败：

| 现象 | 原因 | 处理 |
|---|---|---|
| HTTP 401 | token 缺失或已过期 | 重新登录或更换 API Key |
| HTTP 400/业务 `code` 非 0 | 参数错误、资源不存在、资源不可播放 | 检查编号、命令和速度范围 |
| 请求超时 | 下级平台/设备未响应 DeviceControl | 检查注册、心跳、SIP 路由和设备权限 |
| 返回成功但镜头不动 | 摄像机不是 PTZ、宇视未授权或设备不支持该命令 | 查通道类型和宇视 PTZ 配置 |
| 播放返回成功但浏览器无画面 | RTP/PS 未到达或播放器协议/端口错误 | 查 SDP、10000 端口、返回的媒体 URL 和 WebSocket 101 |

## 7. 外部系统推荐调用流程

1. 登录取得 JWT，或配置服务专用 API Key；
2. 查询设备：`/api/device/query/devices`；
3. 查询通道：设备通道接口并过滤 `resourceType=CHANNEL`；
4. 如果使用统一资源树，记录通道对象的整数 `id`；
5. 调用 `/api/common/channel/play` 或 `/api/play/start`；
6. 选择返回的 `rtc`、`wss_flv`、`hls` 等地址播放；
7. 云台按下/松开分别发送方向/`stop`；
8. 关闭播放时调用对应 stop 接口；
9. 对 401、超时、`code != 0` 做重试和用户提示，但不要无限重试点播或 PTZ。

## 8. 联调检查清单

- WVP Web/API 端口从浏览器和外部系统均可访问；
- 下级平台向 WVP SIP 端口注册并持续心跳；
- 设备 `status=true`，通道 `online=true`；
- 通道 `resourceType=CHANNEL`，不是 `DIRECTORY`；
- 播放 INVITE 后 WVP 能收到 RTP/PS；
- 返回的媒体 URL 从外部客户端可达，HTTPS 页面不混用 `ws://` 或 `http://`；
- WebSocket 播放握手状态为 `101`，不是 `200`；
- PTZ 命令下发时设备在线且已启用 PTZ；
- 方向键释放后确实发送 `stop`；
- 宇视中文目录出现乱码时，双方字符集统一为 GB18030/GBK/GB2312 中的一种，并重新同步目录；
- 生产环境不记录 JWT/API Key，不把真实凭证提交到代码库。
