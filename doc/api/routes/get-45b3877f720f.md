#### 业务约定

参数、名称优先级、应答语义与完整示例见[接入指南第8.2节](../接入指南.md#82-预置位)。名称备注只保存到平台，不进入国标控制指令。

按设备实时逐个查询全部视频通道，排除目录和预置位为空的通道；名称优先使用平台备注。整体timeout默认60秒，范围1–300，每个通道最多等待5秒。整体超时后不再发起后续查询。

只有code=0表示全量查询完成；全部成功且无预置位时data=[]。部分通道失败或未完成时code非0，data仅含已成功查到的非空通道，不可依据此部分结果删除已有预置位。

查询设备当前列表后合并名称：平台备注优先，否则设备名称，否则自动名称；备注不会产生设备查询中不存在的预置位。
