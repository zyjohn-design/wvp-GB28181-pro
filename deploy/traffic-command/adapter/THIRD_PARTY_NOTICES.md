# 第三方开源组件

本适配程序建议与以下开源项目组合部署：

- [WVP-GB28181-pro](https://github.com/648540858/wvp-GB28181-pro)，MIT License。
- [ZLMediaKit](https://github.com/ZLMediaKit/ZLMediaKit)，MIT License。
- [mpegts.js](https://github.com/xqq/mpegts.js)，Apache License 2.0。

本目录没有复制 WVP-GB28181-pro 或 ZLMediaKit 的源代码。`npm install` 会按照
`package-lock.json` 安装 mpegts.js，浏览器运行时从适配服务本地加载它。
